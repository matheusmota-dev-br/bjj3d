# Slider and swatch choices

The two controls of the fighters screen.

## Slider

A label, the range, and **words at both ends** instead of numbers: "Slim … Sturdy" says what
moving it does; 0.85 … 1.2 would not.

<Canvas of={Slider.Build} />

`onFocus` is called when the person reaches for it, before it moves: the site turns the
camera to the body as soon as the slider is touched.

## Swatch choices

Choices shown by their colour: the belts. The chosen one is pressed.

<Canvas of={Slider.Belts} />

```ts
import { slider, swatchChoices } from "@bjj3d/ui";

slider({ label: "Thickness", min: 0.85, max: 1.2, step: 0.01, value: 1, ends: ["Slim", "Sturdy"], onInput, onFocus });
swatchChoices({ items: BELTS.map((b) => ({ value: b, label, color: BELT_COLORS[b] })), value: "white", onPick });
```
