# GrappleMap data

`GrappleMap.txt` is copied unchanged from [Eelis/GrappleMap](https://github.com/Eelis/GrappleMap)
(commit of 2020-03-14). Its authors released code and data into the public domain.

It holds 601 positions and 1,485 transitions of two stick figures with 23 joints each,
no-gi only. The reader is `web/src/grapplemap.ts`.
